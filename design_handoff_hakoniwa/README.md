# ハコニワ — 実装ハンドオフ指示書

> このドキュメントは、**デザインをそのまま保ったまま** ハコニワ アプリを iOS / Android 両対応で実装するための、Claude Code 向け指示書です。会話に参加していない開発者でも、この README だけで実装できるように書かれています。

---

## 0. アプリ概要

**ハコニワ** は、子どもの大切なモノ（ぬいぐるみ・工作・絵など）を **3Dスキャン** して、家族ごとの小さなデジタル空間「ハコニワ」に思い出（写真・こえメモ・メモ）と一緒に残していくアプリ。

- スキャンしたモノは、ドールハウス風の部屋の中に **タップできるピン** として配置され、増えていく。
- ピンをタップすると、そのモノの情報シート（名前・時期・メモ・こえメモ・写真）が下から開く。
- 温かく柔らかい、手描き風・丸ゴシックのビジュアル。親子で使う想定。

---

## 1. このバンドルのデザインファイルについて

`design/` フォルダの中身は、**HTMLで作られたデザインリファレンス**（見た目と挙動を示すプロトタイプ）です。**そのまま製品コードとして出荷するものではありません。**

やってほしいのは、これらのHTMLデザインを **ターゲット環境（下記の推奨スタック）で忠実に作り直す** ことです。レイアウト・色・タイポグラフィ・余白・角丸・アニメーションは、以下の仕様通りに **ピクセル単位で再現** してください。

- `design/ハコニワ アプリ.dc.html` — **本体**。全7画面と画面遷移・状態遷移がすべて入った動くプロトタイプ。ブラウザで開けば実際に触れます。
- `design/assets/room-sample.png` — ハコニワの部屋（ジオラマ）のサンプル画像。
- `design/ios-frame.jsx` `design/image-slot.js` `design/support.js` — プロトタイプを動かすための補助部品。**実装には移植不要**（iPhoneフレームや画像スロットはプレビュー用の足場です）。

### 忠実度: ハイファイ（hi-fi）
このプロトタイプは最終的な色・書体・余白・インタラクションを含む **ハイファイ** です。UIは既存のライブラリやパターンを使いつつ、**見た目はピクセル忠実に** 再現してください。

## 2. 推奨技術スタック

**React Native + Expo** をベースに、**3Dスキャン部分だけネイティブモジュール** で実装する構成を推奨します。

| 領域 | 使うもの |
|---|---|
| フレームワーク | React Native + **Expo**（EAS Build / Submit で両OSビルド・配信） |
| 言語 | TypeScript |
| 画面遷移 | **React Navigation**（native-stack + 下部タブ） |
| カメラ | `expo-camera` |
| 写真選択 | `expo-image-picker` |
| 音声（こえメモ） | `expo-av`（録音・再生） |
| 3D表示（ハコニワ空間） | `expo-gl` + **three.js**（`expo-three`）で glTF/USDZ モデルを表示・回転 |
| 3Dスキャン（フォトグラメトリ） | **ネイティブモジュール**：iOS = Apple **Object Capture**（RealityKit）/ Android = **ARCore** ベース or 外部SDK。まずはダミーUIで実装し、後で差し替えられる構造にする |
| ローカル保存 | `expo-sqlite` または `expo-file-system` + `AsyncStorage`（メタデータ） |
| フォント | `expo-font` で Google Fonts の **Zen Maru Gothic** / **Zen Kaku Gothic New** を読み込む |

### 実装の進め方（重要）
1. **まずスキャン・3D表示・録音をすべてダミーUI**（プロトタイプ通りの見た目だけ）で、全7画面が動くアプリを完成させる。
2. その後、`スキャン` `3D表示` `録音` を1機能ずつ実機能に差し替える。
3. スキャンの中身だけネイティブ、それ以外の全画面は React Native、という切り分けにする。

## 4. 画面一覧（全7画面）

状態は単一の `screen` で切替。プロトタイプの `state` は次の通り：

```
screen:     'onboard' | 'home' | 'scan' | 'memory' | 'space' | 'memories' | 'settings'
progress:   0..20        // スキャンの撮影方向数
recording:  boolean      // こえメモ録音中
child:      'そうた' | 'みお'   // 表示中のハコニワの持ち主
selectedId: string|null  // 部屋で選択中のモノ（情報シート表示）
placed:     boolean      // スキャン保存で「つみき」が追加されたか
justAdded:  boolean      // 追加直後の通知/演出フラグ（数秒で自動オフ）
```

---

### 4-1. オンボーディング `onboard`
- **目的**: 初回起動時のコンセプト紹介。
- **レイアウト**: 縦グラデ背景 `#F6EEDF→#EBDCC3`。中央にハコニワのアイコン（木枠 210×210px、角丸34px、`hako-float` 5秒 ふわふわ上下アニメ、中に room-sample.png、上にオレンジ/グリーンのピン2つ）。
- **コピー**: 見出し「大切なモノを、／思い出と一緒に。」（30px/900、行間1.25）。説明「子どもの宝物を3Dスキャンして、／ちいさなハコニワにのこそう。／写真やこえメモも いっしょに。」（14px/500、行間1.9、`#8B7355`）。
- **ボタン**: 「はじめる」（オレンジ塗り、角丸16px、16pxパディング）→ `home` へ。下に「すでに アカウントを おもちの方」（12px/600、淡色、タップ可）。

### 4-2. ホーム `home`
- **目的**: 家族のハコニワ一覧と最近の思い出、スキャン導線。
- **ヘッダー**: 「こんにちは、ゆいさん」（12px/500淡）＋ロゴ「ハコニワ」（27px/900）＋右に丸アバター42px。下に「大切なモノを、思い出と一緒に。」（13px/500）。
- **家族カード**（2列グリッド、gap14px）: 「そうた」カードと「みお」カード。各カードは白・角丸22px・影付き。上部118pxに room-sample.png（みおは `filter:hue-rotate(18deg) saturate(.9)` で色味変更）、下に名前（15px/700）＋コ数バッジ（**そうた= `sotaCount`（初期24コ、保存後25コ）**／みお= 11コ）＋年齢。タップ → `space`（child切替、selectedIdリセット）。
- **新規カード**（全幅）: 破線ボーダー角丸22px、オレンジ丸＋（径44px）＋「あたらしい ハコニワ／家族のおへやを つくる」。タップ → `scan`。
- **最近ふえた思い出**（見出し13px/700）: 横並び3カード（くまのプー／ねんど／かぞくの絵）。各タップ → そうたの `space`。
- **下部タブナビ**（下記5画面共通、後述）。ホームではホームがアクティブ（`#E08A63`）。

### 4-3. 3Dスキャン `scan`
- **目的**: モノを回り込みながら撮影して3Dモデル化（ダミー）。
- **ヘッダー**: 左＝戻る（丸38px、`<` アイコン）→ `home`。中央「3Dスキャン」（16px/700）。右＝ヘルプ「?」丸。
- **中央**: 対象名「つみき」（15px/700）＋「まわりを ぐるっと写してね」（12px/500淡）。
- **カメラビュー**: 角丸28px・高さ340pxのプレースホルダ（実装ではライブカメラ）。四隅に白いL字ガイド。中央に SVG の円形プログレスリング（半径66px、`#E08A63`、`progress/20` の割合で弧が伸びる）。下に吹き出しヒント（`scanHint`）:
  - `progress/20 ≥ 1.0` → 「キャプチャ 完了！ 右下の完了へ」
  - `> 0.5` → 「あと ちょっと！ 反対がわを写して」
  - それ以外 → 「ぐるっと 一周してね」
- **進捗**: 「キャプチャ 進行ど」＋「`progress` / 20 方向」。下に進捗バー（`progress/20*100%`、幅を0.3sトランジション）。
- **操作行**: 左＝やり直す（`progress`を0に）／中央＝シャッター（径76px、押すたび `progress += 3`、上限20）／右＝完了（`progress/20≥1` のとき不透明・`#8BA36F`、未満は opacity 0.4）→ `memory`。

### 4-4. 思い出をのこす `memory`
- **目的**: スキャン直後にモノへ情報を付ける。
- **ヘッダー**: 戻る → `scan`。中央「思い出をのこす」。右「スキップ」（タップで `space`＝そうた へ）。
- **プレビュー行**: 3Dモデルのサムネ（縞）＋名前入力欄（初期値「つみき」、下線スタイル、17px/700）＋「名まえを つけてね」。
- **写真をそえる**: 写真1・写真2のサムネ（78px角）＋「ついか」破線タイル。
- **こえメモ**: 丸ボタン（`recColor`＝録音中 `#C2452F`／通常 `#E08A63`）＋波形SVG＋ラベル（`recLabel`＝録音中「● 録音中」／通常「0:12」）。タップで `recording` トグル。
- **おもいで メモ**: 白カードのテキスト（例「たかくたかく つみあげて、くずして わらう。まいにち あそんだ つみき。」）。実装では複数行テキスト入力。
- **だれの？／いつ？**: 2列。「そうた」（オレンジ丸＋名）／「2024年 冬」。
- **フッター固定ボタン**: 「ハコニワに しまう」（オレンジ塗り）→ 保存アクション（`saveItem`、次項）。

### 4-5. ハコニワ空間 `space`（★中心画面）
- **目的**: 部屋の中にモノが置かれ、タップで情報を見る。
- **ヘッダー**: 戻る（丸・半透明白）→ `home`。中央にタイトル（`child`＋「の ハコニワ」、17px/900）＋サブ（`count`＋「コの思い出」）。右＝共有アイコン。
- **「置きました」通知**（`justAdded` が true の数秒間だけ表示）: グリーンの帯「ハコニワに『つみき』をおきました」。
- **部屋（ジオラマ）**: 木枠フレーム（`linear-gradient(150deg,#CBA271,#A97C4E)`、角丸24px、パディング11px、大きな影）の中に room-sample.png（高さ300px、角丸15px）。実装ではここが **three.js の3Dルーム**。
  - フレーム上に **モノのピン**（`markers`）を絶対配置（left/top は%）。各ピンは白丸＋色ボーダー＋中央に色ドット。選択中は径38px・ボーダー3px、非選択は径30px・ボーダー2.5px。
  - 左上にサブ（コ数）バッジ、右上に「リセット/回転」ボタンと「＋」（→ `scan`）。
  - **配置データ**:
    - そうた: `bear`(34%,54%,オレンジ) / `clay`(70%,60%,グリーン) / `draw`(78%,26%,イエロー)。`placed` が true なら4つ目 `blocks`(52%,30%,ブルー) が追加（追加直後は `hako-pulse` 1.4s×2 の波紋アニメ）。
    - みお: `shoes`(30%,58%,オレンジ) / `toy`(64%,52%,グリーン) / `photo`(76%,30%,イエロー)。
  - ピンをタップ → `selectedId` にセット → 情報シート表示。
- **情報シート**（`selectedId !== null` のとき、下部）: 白カード角丸24px、上部にグレーのつまみ、右上に×（`selectedId` を null に）。左に写真サムネ（82px角）、右に名前（16px/700）＋日付バッジ＋メモ（11.5px/1.55）＋「こえメモ 0:12」チップ（タップで録音トグル）＋「写真 3まい」。
- **未選択時**: 情報シートの代わりに「＋ スキャンして モノをふやす」ボタン（→ `scan`）。
- **モノのデータ**（`items`）:

### 4-6. おもいで（タイムライン）`memories`
- **目的**: 全思い出を時系列（新しい順）で一覧、検索・絞り込み。
- **ヘッダー**: 「おもいで」（24px/900）＋「ぜんぶで `totalCount` コ ・ 古いものから いまへ」（`totalCount`＝35、`placed`時36）。検索バー（プレースホルダのみ）＋フィルタチップ「すべて/そうた/みお」。
- **タイムライン**: 左に縦線＋年ドット、右にカード（モノ名＋持ち主バッジ＋メモ2行省略）。`placed` が true なら先頭に「つみき（2024・新規）」。各カードタップ → その子の `space` を開き該当モノを選択（`selectedId`）。
- 並び順（新しい順）: [placed時: つみき] → かぞくの絵(2024,そうた) → ねんど工作(2023,そうた) → たんじょう日(2023,みお) → がらがら(2021,みお) → はじめての靴(2021,みお) → くまのプーさん(2019,そうた)。

## 6. 画面遷移・状態遷移まとめ

```
onboard --はじめる--> home
home --そうた/みおカード--> space(child切替, selectedId=null)
home --新規カード/のこすタブ--> scan(progress=0)
home --最近の思い出--> space(そうた)
scan --シャッター×n--> progress+=3 (max20)
scan --やり直す--> progress=0
scan --完了(progress≥20)--> memory
scan --戻る--> home
memory --ハコニワにしまう--> space(child=そうた, selectedId='blocks', placed=true, justAdded=true→3.2秒後false)
memory --スキップ--> space(そうた)
memory --戻る--> scan
space --ピンtap--> selectedId=そのid（情報シート表示）
space --シート×--> selectedId=null
space --＋--> scan
space --戻る--> home
memories --カードtap--> space(その子, 該当モノ選択)
settings --オンボもう一度--> onboard
（下部タブは各画面から home/memories/scan/settings へ）
```

### アニメーション
- 画面切替: `fade` 0.28s ease（opacity 0→1）。
- 新規ピン追加: `hako-pulse` 1.4s ease-out ×2（青の波紋が広がって消える）。
- オンボのアイコン: `hako-float` 5s ease-in-out infinite（±5px 上下）。
- ボタン押下: `scale(.96)` + わずかに暗く（`.tap:active`、0.12s）。
- 進捗バー: width を 0.3s ease でトランジション。
